```
/login ── [LearnID] หรือ [Google] ──► เลือกบัญชีตัวอย่าง
   ├─ พี่ ───────────────────────────────► /tutor
   ├─ น้อง มี MyPath แล้ว ───────────────► /mypath

        ├─ Google และยังไม่มีชื่อเล่น/ชั้น ─► /welcome (ชื่อเล่น + ม.4/5/6/ซิ่ว) ─┐
```

## น้องสร้าง MyPath (`/create`, 4 ขั้น + progress bar)

```
[1 เป้าหมาย] ─► [2 วิชาที่ต้องสอบ] ─► [3 เวลาเรียน] ─► [4 ดูแผน] ─ ตกลง ─► /mypath
     │                                                     │
     └─ "มีโค้ด MyPath?" ── โค้ดถูก ──────────────────────────┼──────────► /mypath
                                                           └─ ยังไม่ชอบ ─► กลับไปขั้น 3 หรือ 1
```

1. **เป้าหมาย** — มีตัวอย่าง 3 อันดับ (วิศวะคอม ม.กาฬสินธุ์ · วิศวะคอม จุฬาฯ · จิตวิทยา จุฬาฯ) · เพิ่มด้วยการค้นหา + chip กรอง (กลุ่มสาขา, มหาวิทยาลัย) หรือไล่ มหาวิทยาลัย → คณะ → หลักสูตร · สูงสุด 7 · ลากวาง + ปุ่มขึ้น/ลง · แต่ละการ์ดมี chip วิชาสอบ + % (4 ตัวแรก แล้ว +N) · ใต้รายการมี "วิชาที่ต้องสอบรวม" อัปเดตทันที
2. **วิชาที่ต้องสอบ** — หน้าโหลด ~2 วินาที (รวมวิชาสอบ → จัดลำดับความสำคัญ → วางคอร์ส) แล้วสรุปวิชาแยกตามช่วงเรียน (ความเข้าใจ → ฝึกฝน → ท่องจำ → ลุยโจทย์) ป้ายใช้ทุกอันดับ / ใช้ N อันดับ · "ยังไม่มีคอร์สใน prototype" · หมายเหตุ เกรด / portfolio / either · เตือนหลักสูตรที่ยังไม่มีข้อมูลวิชาสอบ · ไม่ถามความถนัด
3. **เวลาเรียน** — เลือกโรงเรียน (บังคับ ใส่ช่วงปิดเทอมให้อัตโนมัติ) · slider แบบ MyPath วันเรียน (ค่าเริ่ม 2) วันหยุด (ค่าเริ่ม 4) 0–10 ทีละ 1 · ผลรวมต่อสัปดาห์
4. **ดูแผน** — สรุป + ช่วงทบทวนก่อนลุยโจทย์ + MyPath มุมมอง All ของแผนร่าง · ตกลง ใช้แผนนี้ / ยังไม่ชอบ ปรับใหม่

ระหว่าง flow แถบบนมีแค่โลโก้ + "ยกเลิก" · ยกเลิกแล้ว MyPath เดิม (ถ้ามี) ไม่เปลี่ยน

## น้องที่มี MyPath แล้ว (`/mypath`)

แถบบน: โลโก้ · "สร้าง MyPath ใหม่" · avatar (ชื่อ, ชั้น, ออกจากระบบ) · ถ้าพี่เพิ่งแก้ มี banner "ปรับโดยพี่"
สร้างใหม่ → กล่องยืนยัน → `/create` เติมค่าเดิม → แทนที่เมื่อตกลงเท่านั้น

## พี่

```
/tutor (รายชื่อน้องทุกคน ~25 คน)
  กรอง: ชื่อ · ชั้น · วิชาที่เรียน · สถานะ (ยังไม่สร้าง / ปกติ / เกินเวลาเรียน)
  └─► /tutor/:id
        ข้อมูลน้อง (ชื่อ ชั้น login ด้วย แก้ล่าสุด)
        การ์ดเป้าหมาย [แก้เป้าหมาย] ─► ขั้น 1–2 ─┐
        การ์ดเวลาเรียน [แก้เวลาเรียน] ─► ขั้น 3 ───┴► ดูแผน ─► บันทึกทันที + แจ้งน้อง
        MyPath ของน้อง (แก้ได้ทันที)
        ยังไม่มี MyPath → [สร้าง MyPath ให้น้อง] (flow สร้าง + banner "กำลังทำแทนน้อง")
```
