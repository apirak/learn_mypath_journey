# น้องมี MyPath ที่ใช้งานได้หนึ่งอัน แทนที่เมื่อกดตกลงเท่านั้น

"สร้าง MyPath ใหม่" เปิด flow สร้างโดยเติมเป้าหมายและเวลาเรียนเดิมไว้ ทุกอย่างระหว่าง flow เป็นร่าง ยกเลิกได้โดย MyPath เดิมไม่เปลี่ยน MyPath เดิมถูกแทนตอนกด "ตกลง ใช้แผนนี้" ในขั้นดูแผน หรือใส่โค้ด MyPath ถูกต้อง (มีกล่องยืนยันก่อนเมื่อมี MyPath อยู่แล้ว)

## Considered Options

- **เก็บหลาย MyPath แล้วสลับ:** ไม่เลือก เพราะเพิ่มคำถามว่าแผนไหนคือแผนที่พี่ดู และซ้อนกับแนวคิด "อันดับ" ที่ใช้แทนแผนสำรองได้อยู่แล้ว

## Consequences

- การซื้อและความคืบหน้าเป็นของน้อง ไม่ใช่ของ MyPath จึงไม่หายเมื่อสร้างใหม่
