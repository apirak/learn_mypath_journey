# พี่แก้ MyPath ของน้องได้ทันที แล้วแจ้งน้องด้วย banner

พี่เห็นน้องทุกคน เปิด MyPath ของน้องแบบแก้ได้ (component เดียวกับที่น้องใช้) และแก้เป้าหมาย / เวลาเรียนผ่านขั้นเดียวกับ flow สร้าง การแก้มีผลทันที น้องเห็น "ปรับโดยพี่" บนหน้า MyPath บอกว่าใครแก้ เมื่อไร และแก้อะไร น้องที่ยังไม่มี MyPath พี่สร้างให้ได้

## Considered Options

- **พี่ส่งเป็นข้อเสนอ น้องกดยอมรับ:** ไม่เลือกใน prototype เพราะเพิ่ม state "รอยอมรับ" และหน้าเทียบก่อน/หลัง ถ้าทดสอบกับน้องจริงแล้วรู้สึกถูกยึดแผน ค่อยกลับมาดูทางนี้
- **จำกัดให้พี่เห็นเฉพาะน้องที่ดูแล:** ไม่เลือก ตามที่ทีมกำหนดให้พี่เห็นทุกคน

## Consequences

- ต้องเก็บ "แก้ล่าสุดโดยใคร เมื่อไร แก้อะไร" ไว้กับ MyPath ของน้อง
